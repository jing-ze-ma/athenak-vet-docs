Requirements
============

+------------+---------------------------------------+---------------------------------------+
| for        | what                                  | version                               |
+============+=======================================+=======================================+
| CPU build  | C++17 compiler, MPI (``mpicxx``),     | GCC 11 or newer (13 used), Open MPI   |
|            | CMake                                 | 4.1 or 5.0, CMake 3.20 or newer       |
+------------+---------------------------------------+---------------------------------------+
| NVIDIA GPU | CUDA toolkit + host GCC               | CUDA 12.6 or 12.9 with GCC 13 (not    |
|            |                                       | CUDA 12.2, not CUDA 13; see 3b)       |
+------------+---------------------------------------+---------------------------------------+
| AMD GPU    | ROCm (``hipcc``)                      | ROCm 7.2                              |
+------------+---------------------------------------+---------------------------------------+
| tests      | python3 + numpy                       | any recent                            |
+------------+---------------------------------------+---------------------------------------+
| plots      | matplotlib, jupyter                   | any recent                            |
+------------+---------------------------------------+---------------------------------------+

On a cluster, load these as modules first (examples in :doc:`build`). The Python packages:

.. code:: bash

   python3 -m pip install --user numpy matplotlib jupyter
